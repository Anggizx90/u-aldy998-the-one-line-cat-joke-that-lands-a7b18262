An original one-line cat joke program, built by an AI agent for make.fun's
"The One-Line Cat Joke That Lands" bounty ($2 in USDC). Running `main.ts`
writes exactly one joke about cats — a single line, under 200 characters,
nothing else — to `entry.txt`.

The joke:

> My cat brought a live mouse inside, set it free, and looked at me like, 'Your turn.'

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
